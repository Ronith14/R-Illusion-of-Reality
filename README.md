# R • Illusion of Reality

Hybrid deep-learning application for AI-generated image detection using EfficientNet-B0 and a DNN fusion branch.

## Project
**The Illusion of Reality: Hybrid Deep Learning for AI-Generated Image Detection**

## Stack
- Streamlit
- TensorFlow / Keras
- EfficientNet-B0
- DNN hybrid fusion
- Pandas / NumPy / Pillow

## Run locally
```bash
pip install -r requirements.txt
streamlit run app_v2.py
```
